Bridge Stress Testing Project
This folder contains documentation, and photos from a project where I used a structural simulation program to stress‑test bridge designs. The goal of the project was to analyze how different bridge structures respond to load, identify weak points, and understand how material and geometry affect overall strength.

About This Folder
I no longer remember the name of the simulation software used, and the original project files were not preserved. Because of that, this folder includes:

photos of the bridge models and simulation results

videos showing the stress tests

notes describing the testing process and findings

This repository serves as a record of the project even without the original simulation files.

What’s Included
bridge model photos

stress test videos

load analysis notes

failure point observations

Skills Demonstrated
structural analysis

simulation interpretation

material behavior understanding

problem solving and debugging

technical documentation
